# Convenant

Decidimos desenvolver um jogo no qual o usuário enfrenta um boss em uma batalha por turnos. Durante o combate, o usuário realiza seu ataque primeiro e, em seguida, o boss executa sua ação. Esse ciclo se repete até que um dos dois seja derrotado.

Para manter o desafio e buscar um maior equilíbrio na dificuldade, o dano causado pelo boss aumenta progressivamente a cada turno (Dano do boss * 0,25) .Da mesma forma, buscamos ajustar o dano causado pelo usuário para que o combate permaneça desafiador, evitando que a batalha se torne fácil demais ou excessivamente difícil.
